## 4. 仍需跟进

1. **DB 里的场景 instructions 仍含“重复你的核心疑问”**：代码侧 `sanitizePatientInstructions` 已经在投影层替换，不需要改库就能生效；如果要把原始数据也清干净，再单独跑 SQL（先备份），同时处理 `hidden_config.instructions` 和 `variants[].instructions`。不要动 `opening`，开场白仍由 `createSession` 使用。
2. **v2 RAG 端到端**：需要 8765 embedding 起来，跑一场 `context_version=2` 的会话 + 报告；本次只验证了 v1/编译/单测。
3. **报告 `strengths` / `improvements` 为空仍 503**：`reportArray(..., 1, 10)` 要求至少 1 项；模型偶尔不返回就会整份失败。可改成空时用保守兜底，或只降级该区块。
4. **长报告没有历史裁剪**：`finish_reason=length` 时现在只收紧预算；如果 prompt 本身太长，仍可能 3 次重试后 dead。
