## 三、验收路径（照着点）

底部有 5 个 tab：**首页 / 培训 / 训练 / 数据 / 我的**。

### A. 学员端（需要先切"学员视角"）

| # | 改了什么 | 从哪进 | 该看到什么 |
|---|---|---|---|
| 1 | **弱项 → 一键复练**（P0-4）| 「我的」→ **个人成长** → 弱项卡片 → 「复练「X」相关场景 ›」| 进入**复练候选页**：卡片按该维度适配度排序，显示**比重百分位**、已练次数、该维度历史均分；有进行中训练时按钮是「继续」而不是「新建」|
| 2 | **进阶档**（P1-1）| 「训练」tab → 任一场景卡 → 「**挑战进阶档 ›**」| 先弹确认框，**明确写着成绩不计入计划达标**；进入训练页后头部常驻「进阶档」标识；患者开场白比标准档更冲 |
| 3 | **报告页对照**（本轮新增）| 完成一次训练 → 自动进报告页；或「数据」tab → 报告 → 选历史报告 | 「严重违规」与「关键轮次点评」两区都是**两栏对照**（灰条=你当时说的 / 蓝条=建议这样说）；点评默认显示 **3 条**而不是 1 条；含违规的轮次右上角有**「该轮含违规」**标记 |
| 4 | **计划达标口径文案**（P0-1/P2-2）| 「我的」→ 培训计划（或报告页 → 训练计划）| 要求行写的是「完成 ≥ N 次 · 目标维度均分 ≥ X 分」；计划开了逐次达标时，文案变成「**每次 ≥ X 分**」|

### C. 顺带可看的两个细节

- **报告页「还有 N 个」**：以前只显示 1 条、提示「还有 4 个」；现在显示 3 条、提示「还有 2 个」——这个数字差就是改动本身。
- **进阶档不计入计划**：学员练了进阶档之后，主管端计划详情里的完成次数**不应增加**（这是刻意的，避免"勇于挑战反而拖累计划"）。

| **报告页对照改版** | 完成训练 → 报告 | 两栏色条的视觉、长话术（20–100 字）在窄屏下的折行是否可读 |

这 4 处是**唯一一类"代码写了但没人真正看过它长什么样"**的欠账，其余功能都有真实数据的端到端验证兜底。

## 五、验收时可能遇到的"看起来像 bug、其实不是"

| 现象 | 原因 |
|---|---|
| AI 生成骨架一直失败 / 停在「生成中」 | 演示环境**没配模型 Key**，属预期。配好 `DEEPSEEK_API_KEY` 后可用 |
| 报告页提示「任务仍在后台可靠执行」 | 评分是异步任务，稍等或从历史记录再进一次 |
| 学员端接口报「管理员账号不能使用学员训练」 | 没切身份 —— 去「我的」→ 切换学员视角 |
| 某学员计划「已按综合均分判定」 | 该学员在计划窗口内**没有**目标维度的有效评分，属有意的回退，页面已明示 |
| 主管端某些接口 403「仅主管可…」 | 当前是学员身份 |
