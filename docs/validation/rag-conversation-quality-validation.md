# RAG 对话质量修复验证

## 行为变化

- AI 患者直接生成短句，后端保留引用审计，不再拼接知识原文。个人预算按固定画像披露；取消逐轮追加比较诊所；纠正否定承诺判断和告别条件。
- v1/v2 训练提示按当前对话生成。v2 只传公开画像和对话，不传未披露私有信息。提示最多 80 字；违规、超长或重复内容不保存、不消耗次数，不回填固定文案。
- 客服资料不足时根据历史说明具体查询限制；不承诺代查、回访或完成预约。教学卡默认折叠，历史教学内容和引用仍可查看。
- 模型正文读取失败明确报错。患者及提示请求留出推理预算；其它调用截断后仍最多重试一次，但额度至少提高到 6000，上限 8192。

## 受控真实模型评估

使用个人配置的 `deepseek-flash`，读取演示服务锁定快照，在内存维护对话，不向原训练会话写入消息或提示。

- 患者迭代测试累计 30 轮，回复 18–47 字，覆盖费用、含糊输入、承诺纠正、预算披露、角色诱导和告别。各批次结束时原会话快照一致。
- 最终提示/客服补测：6 个提示场景和 5 轮连续客服对话全部完成。提示 19–38 字，客服 3–53 字。
- 最终补测共 13 次 HTTP 请求，含两次自动重试；一条客服回复在上游 JSON 格式失败后，经安全校验返回短兜底，没有对话中断。
- 初测中提示过度转交医生、客服承诺代查的行为已据实测修正；最终怕疼提示为“您更担心操作时疼，还是结束后的不舒服？”。

有限样例不证明任意输入都自然；合法的短兜底仍保留。真实抽测覆盖模型、检索和渲染，提示落库/次数由离线数据库集成测试覆盖，二者不混同。
