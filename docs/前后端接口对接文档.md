```
Base URL:        http://127.0.0.1:8080/api   (开发)

请求头:
  Content-Type: application/json
  X-Demo-User-Id: demo-user-001
```

#### 4. `POST /sessions` — 创建会话

**请求**:
```json
{ "scenarioId": "implant-basic" }
```

**响应**:
```json
{
  "code": 0, "message": "ok",
  "data": {
    "session": {
      "id": "sess_xxx",
      "scenarioId": "implant-basic",
      "status": "in_progress",
      "currentRound": 0,
      "maxRounds": 10,
      "evaluationStatus": "not_started"
    },
    "messages": [
      { "id": "msg_xxx", "role": "patient", "content": "您好…", "round": 0, "createdAt": "..." }
    ]
  }
}
```

**冲突处理**: 同场景已有 `in_progress` 会话 → `409 SESSION_IN_PROGRESS`

#### 5. `GET /sessions/:id` — 会话详情

**响应**:
```json
{
  "code": 0, "message": "ok",
  "data": {
    "session": {
      "id": "sess_xxx", "scenarioId": "implant-basic", "scenarioName": "种植牙基础咨询",
      "status": "in_progress", "currentRound": 2, "maxRounds": 10,
      "startedAt": "...", "updatedAt": "...", "finishedAt": null,
      "totalScore": null, "evaluationStatus": "not_started"
    },
    "messages": [ ... ],
    "pendingMessage": null
  }
}
```

**pendingMessage**: 若上一条消息因模型超时未回复，返回 `{ clientMessageId, content, round }`，前端用相同 `clientMessageId` 重试。

---

#### 6. `POST /sessions/:id/messages` — 发送消息

**请求**:
```json
{ "clientMessageId": "client-msg-0002", "content": "我理解您的担心…" }
```

**约束**:
- `content` 去首尾空白后 1-1000 字符
- 会话必须 `in_progress`
- 轮数达到 10 后拒绝
- `clientMessageId` 实现幂等

**响应**:
```json
{
  "code": 0, "message": "ok",
  "data": {
    "userMessage": { "id": "...", "role": "user", "content": "...", "round": 1, "createdAt": "..." },
    "patientMessage": { "id": "...", "role": "patient", "content": "...", "round": 1, "createdAt": "..." },
    "session": { "currentRound": 1, "remainingRounds": 9, "status": "in_progress", "shouldFinish": false }
  }
}
```

> 模型超时 → `503 MODEL_TIMEOUT`；用户消息已保存，可相同 `clientMessageId` 重试。

---

#### 7. `POST /sessions/:id/finish` — 结束训练

**请求**:
```json
{ "reason": "manual" }
```
`reason`: `manual`、`max_rounds`、`model_error`

**规则**:
- `currentRound === 0` 返回 `422 MIN_ROUNDS_NOT_REACHED`
- 幂等：已结束会话重复调用返回当前状态

**响应**: `202`
```json
{
  "code": 0, "message": "accepted",
  "data": { "sessionId": "sess_xxx", "status": "completed", "evaluationStatus": "generating" }
}
```

---

#### 8. `POST /sessions/:id/restart` — 重新开始

原子操作：旧会话 → `abandoned` → 创建新会话 → 返回新会话 + 开场消息。

#### 9. `GET /sessions/:id/evaluation` — 评分报告

状态流程:

| status | 说明 | 前端行为 |
|---|---|---|
| `generating` | 评分生成中 | 间隔 2 秒轮询，最多 30 秒 |
| `ready` | 评分完成 | 展示完整报告 |
| `failed` | 评分失败 | 显示"重新生成"按钮 → 调用 retry |

**ready 响应**:
```json
{
  "code": 0, "message": "ok",
  "data": {
    "sessionId": "sess_xxx", "status": "ready", "retryable": false,
    "evaluation": {
      "sessionId": "sess_xxx", "status": "ready",
      "totalScore": 82,
      "dimensionScores": {
        "knowledgeAccuracy": 80, "medicalCompliance": 90,
        "empathy": 88, "needsDiscovery": 75, "serviceEtiquette": 86
      },
      "summary": "…",
      "strengths": [{ "round": 1, "evidence": "…", "content": "…" }],
      "improvements": [{ "round": 2, "content": "…" }],
      "violations": [{ "round": 3, "originalQuote": "…", "type": "疗效保证", "reason": "…", "deduction": 30, "recommendedRewrite": "…" }],
      "roundComments": [{ "round": 2, "userMessage": "…", "comment": "…", "recommendedRewrite": "…" }],
      "modelVersion": "...",
      "generatedAt": "…"
    }
  }
}
```

**五维权重**:

| 字段 | 中文名称 | 权重 |
|---|---|---|
| `knowledgeAccuracy` | 口腔知识准确性 | 25% |
| `medicalCompliance` | 医疗合规 | 25% |
| `empathy` | 情绪识别与同理心 | 20% |
| `needsDiscovery` | 需求挖掘 | 20% |
| `serviceEtiquette` | 服务礼仪 | 10% |
