# N05 知识核验器与确定性评分

日期：2026-09-22。基于 N04，未合并上游。

## 交付边界

新增 `knowledge_evaluator.h`：候选原句校验、结构化字段扫描、锁定证据验证、六类判定、按知识点去重、显式纠正、加权知识分及五维总分的纯函数。`IModelGateway::extractKnowledgeClaims` 使用现有 DeepSeek 结构化输出与重试器，仅提取轮次、原句、字段；模型提供的分数、结论、数值和偏移不参与计算。

`Service::assessTrainingKnowledge` 为 N06 提供只读接口，仅接受已结束的 v2 会话；读取会话锁定 manifest，以 ClaimVerification 目的逐项检索，不在数据库写事务内调用模型。输出尚未自动写入正式评分报告；evaluation job 分流、报告/公开轨迹的原子提交、结果页展开与错题派生属于 N06。旧版及当前正式报告流程未被替换。

## 固定规则

- 金额按分比较，区分起价、固定价和范围；检查计价单位、条件和有效期。范围内的明确估计按不完整处理，不能当作确定报价。
- 时间区分就诊、疗程和复诊，支持分钟/小时换算，不将月份硬换成天数；预计时长被保证完成时判矛盾。
- 包含项目保留限定；未知新增项目不被认证为正确。已发布预约资料不是实时号源，锁定实时号源的承诺判矛盾。
- 疑问、否定、假设、竞品或患者转述不当作本诊所承诺；“不是…而是…”仅在非转述、非假设时提取后半断言，同时保留完整原句。
- 同一结构化字段为一个计分单元，错误重复不增加分母。明确纠正后采用新的可判定结果，保留全部过程；资料不足的“纠正”不能抹去已证实错误。
- 患者已询问且资料可答、学员有回应机会却未回答时记零分单元；需要医生评估的合理转介不按未回答扣分。末轮患者新增问题不要求不存在的下一轮回答。
- 价格、包含关系和可识别临床风险专业事实权重 2，其余 1；正确 1、不完整 0.5、错误或未回答 0。未知、冲突、不适用不计入准确率分母。
- 零可判定单元时知识分、总分、通过状态均为 null。否则沿用知识 25%、合规 25%、同理心 20%、需求 20%、礼仪 10%，不重新分配权重。知识错误和合规违规保留不同理由，核验器不重复修改合规维度。

## 保守解析边界

专业解释目前仅对与有效证据原文完全相同的陈述认证为 supported；无法确定的同义改写不猜测对错，返回 evidence_missing。未支持的中文数字、货币缩写及含多个不同时间片段的复杂表述同样保守处理。结构化事实即使模型漏提取也会由服务端扫描；专业语义召回仍受提取质量影响，不能声称全部知识已核实。后续扩展解析规则必须增加固定标注用例，不能放开模型自定分数。

每个核验项包含完整原句、UTF-8 字节偏移、引用及锁定期望事实；未回答项单独标注 sourceRole=patient、patientQuestion，不伪造学员原句。knowledgeTraces 仅为待持久化的内部证据快照，本阶段不公开；N06 必须在获胜事务中分配持久 trace ID 并替换引用。
